# Sri Kesava Fertilizers

A web-based label-making project for Sri Kesava Fertilizers, designed to support the preparation and printing of fertilizer product labels.

## 📌 Overview

Sri Kesava Fertilizers is a project focused on simplifying the creation of fertilizer labels through a web-based interface.

The project is being developed to make label preparation more convenient and organized, with the goal of supporting label layouts suitable for printing on compatible label printers.

## ✨ Features

* **Web-Based Interface:** Access the label-making interface through a web browser.
* **Fertilizer Label Design:** Prepare labels for fertilizer products.
* **Print-Oriented Layouts:** Design labels with printing requirements in mind.
* **Local Server:** Run the application locally using Node.js.
* **Customizable Project:** Extend the application with additional label formats and printing functionality.

*Note: Features depend on the current implementation and may be expanded during development.*

## 🚀 Getting Started

### Prerequisites

Install the following software before running the project:

* [Node.js](https://nodejs.org/)
* A modern web browser
* A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/chakrinalam/Sri_Kesava_Fertilizers.git
```

### 2. Navigate to the Project Directory

```bash
cd Sri_Kesava_Fertilizers
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
node app.js
```

If the server starts successfully, the terminal will display a local server address.

### 5. Open the Application

Open the address displayed in your terminal in your web browser.

For the current server configuration, the address is:

http://localhost:3000/

## 🖨️ Label Printing

The project is intended to support fertilizer label preparation and printing workflows.

Printing functionality depends on the label layout, printer compatibility, and the implementation available in the project.

Before printing labels:

1. Verify the label dimensions.
2. Check the printer configuration and media settings.
3. Confirm that the label layout fits the selected label size.
4. Print a test label before starting a full batch.

## 🔧 Development

To modify the application:

1. Open the repository in Visual Studio Code.
2. Edit the frontend files inside the `public` directory.
3. Update `app.js` when server-side changes are required.
4. Run the application locally and verify your changes in the browser.
